Automatic backup actions

Clear inventory

Permanently removes all products from your active stock list so you can start fresh (for example before a new CSV import). Products linked to past sales are deactivated instead of deleted so reports stay intact. This cannot be undone.

Factory reset

This will permanently delete ALL data including products, sales, customers, layby transactions, users, and settings. The database will be reset to factory defaults with a new admin user (username: admin, password: admin). This action CANNOT be undone.
